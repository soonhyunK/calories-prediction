# 🔥 신체 활동 기반 칼로리 소모량 예측

> **리더보드 RMSE 0.06642 달성** | 2단계 앙상블 파이프라인 | 도메인 지식 기반 피처 엔지니어링

---

## 📌 프로젝트 개요

운동 시간, 심박수, 체온, 체중 등 신체 활동 데이터를 기반으로  
칼로리 소모량을 정밀 예측하는 머신러닝 모델을 개발했습니다.  
물리치료사로서 쌓아온 운동 생리학 지식을 피처 설계에 직접 활용하였습니다.

| 항목 | 내용 |
|------|------|
| 과제 유형 | 회귀 (Regression) |
| 데이터셋 | Train 7,500건 / Test 7,500건 |
| 평가 지표 | RMSE |
| 최종 성과 | **리더보드 RMSE 0.06642** |

## 🔍 핵심 전략

### 1. 2단계 파이프라인
어려운 회귀 문제를 두 개의 단순한 문제로 분해

- **Phase 1** — Ridge 회귀 (alpha=1e-9)로 소수점 단위 정밀 예측값 생성
- **Phase 2** — RF · XGBoost · LightGBM으로 소수점을 올릴지(1) 버릴지(0)만 판단

### 2. 도메인 기반 피처 엔지니어링
운동 생리학 지식을 바탕으로 9개 파생 피처 설계

| 피처명 | 공식 | 설계 근거 |
|--------|------|----------|
| d_bpm | 운동 시간 × 심박수 | 운동 강도 지표 |
| d_age | 운동 시간 × 나이 | 연령 보정 운동량 |
| d_weight | 운동 시간 × 체중 | 체중 보정 운동량 |
| bpm_age_ratio | 심박수 / 나이 | 신체 효율 지표 |
| bpm_temp | 심박수 × 체온 | 심혈관 부하 지표 |
| dur_sq | 운동 시간² | 비선형 효과 반영 |

### 3. 성별 분리 학습
- 남성(is_male=1)과 여성(is_male=0)을 독립적으로 학습
- 성별 패턴 차이가 단일 모델에서 노이즈로 작용하는 문제 해결

### 4. 9-Fold Mode Voting 앙상블
- 홀수 fold → 다수결에서 동점 없음
- 9개 fold 예측값을 scipy mode()로 집계 → 단일 모델 오류 상쇄

## 📊 모델 비교

| 모델 | 분할 방식 | 선택 이유 |
|------|----------|----------|
| XGBoost | 깊이 우선 (Level-wise) | 높은 정확도 + L1/L2 정규화 |
| LightGBM | 리프 우선 (Leaf-wise) | 빠른 학습 + 높은 메모리 효율 |
| RandomForest | 배깅 (Bagging) | 과적합 저항 + 앙상블 다양성 |
